SentinelShare 로그 형식 스펙 (Wazuh 연동용)
작성일: 2026-03-16
================================================================

----------------------------------------------------------------
기본 원칙
----------------------------------------------------------------
- 형식     : JSON 한 줄 (NDJSON — 줄바꿈으로 구분)
- 출력 대상 : stdout + 파일 /opt/app/logs/app.log
- 인코딩   : UTF-8
- 타임존   : UTC (ISO 8601)

----------------------------------------------------------------
공통 필드 (모든 로그에 반드시 포함)
----------------------------------------------------------------
timestamp   string   ISO 8601 UTC          "2026-03-16T12:00:00.000Z"
level       string   info / warn / error   "warn"
event       string   이벤트 식별자          "AUTH_FAILURE"
ip          string   클라이언트 IP          "1.2.3.4"
method      string   HTTP 메서드            "POST"
path        string   요청 경로              "/auth/login"
status      number   HTTP 응답 코드         401
latency_ms  number   처리 시간 (ms)         320

----------------------------------------------------------------

{
  "timestamp": "...",
  "level": "warn",
  "event": "AUTH_FAILURE",

  "method": "POST",
  "path": "/auth/login",

----------------------------------------------------------------
로그에 절대 포함하지 않는 값
----------------------------------------------------------------
password / password_hash   크리덴셜 노출 방지
stored_key                 S3 내부 경로 노출 방지
share token 전체 값         유효 토큰 노출 방지
JWT 토큰 전체 값             세션 하이재킹 방지

----------------------------------------------------------------
파일 출력 경로 (EC2 배포 기준)
----------------------------------------------------------------
/opt/app/logs/app.log

  <localfile>
    <log_format>json</log_format>

  </localfile>
